# Bart Banho & Tosa Manager 🐾

## Sobre o projeto

O Banho & Tosa Manager é um sistema web desenvolvido para auxiliar na organização e gerenciamento de um pet shop, facilitando o controle de clientes, pets, serviços e agendamentos.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de criar uma interface simples, intuitiva e funcional.

## Objetivo

Desenvolver uma aplicação web que facilite a rotina de um estabelecimento de banho e tosa, permitindo organizar informações e acompanhar os atendimentos de forma prática.

## Funcionalidades

- Dashboard com resumo dos atendimentos
- Cadastro de clientes
- Cadastro de pets
- Agendamento de serviços
- Controle de status dos atendimentos
- Busca de clientes e pets
- Gerenciamento de serviços
- Armazenamento de dados no navegador

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
